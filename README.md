# BlueDot Labs - Investor Portfolio Page

A single-page portfolio for BlueDot Labs to share with investors.

## Live Site

[https://kunalshaw79.github.io/bluedot-investor-page](https://kunalshaw79.github.io/bluedot-investor-page)

## Local Development

1. Clone the repository
2. Open `index.html` in a browser

No build step required - pure HTML/CSS/JS.

## Deployment

This site is deployed via GitHub Pages from the `main` branch.

To update:
1. Make changes
2. Push to main
3. Changes are live within minutes

## Structure

- `index.html` - Main page
- `styles.css` - Styling
- `script.js` - Animations
- `assets/` - Videos and images
